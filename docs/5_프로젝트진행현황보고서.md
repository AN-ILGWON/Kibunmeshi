## 1. 프로젝트 개요

### 프로젝트 목표
- 사용자가 현재 기분을 선택하면, 그 기분에 맞는 음식을 추천하는 웹 서비스
- 추천 결과를 "카드" 형태로 자동 저장하여 "감정 일기"로 관리
- 유희왕/포켓몬 카드 스타일의 UI 제공

### 현재 진행률: **약 90% 완료** ✅

## 최근 변경 사항 (2026-07-22)
1. **한국어 텍스트 전면 제거**
   - 모든 템플릿 파일(`top.html`, `category.html`, `result.html`, `mypage.html`, `login.html`, `signup.html`, `result-empty.html`)에서 한국어를 제거하고 일본어만 남김
   
2. **회원가입 기능 강화**
   - 비밀번호 확인 필드 추가 및 유효성 검사
   - 닉네임 중복 확인 기능 추가
   - `UserMapper.java`에 `countByNickname()` 메서드 추가
   - `UserService.java`에 `isNicknameAvailable()` 메서드 추가
   - `AuthController.java`에 비밀번호 확인 로직 추가
   
3. **데이터 영구 저장 설정**
   - `application.yml`에서 `spring.sql.init.mode=never`로 변경 → 애플리케이션 재시작시 데이터가 삭제되지 않음
   
4. **개발용 디버그 기능 추가**
   - `DebugController.java` 추가 → `/debug/users`로 DB에 저장된 모든 유저 확인 가능 (개발용으로만 사용, 나중에 삭제 권장)
   - `UserMapper.java`에 `findAll()` 메서드 추가
   - `UserMapper.xml`에 `findAll` 쿼리 추가

## 2. 완료된 기능

### 2.1 코어 기능 (MVP)
| 기능 | 상태 | 설명 |
|------|------|------|
| 기분 선택 화면 | ✅ 완료 | 6가지 기분(기쁨, 슬픔, 화남, 피곤, 신남, 평온) 선택 가능 |
| 음식 카테고리 선택 | ✅ 완료 | 5가지 카테고리(한식, 양식, 중식, 일식, 기타) 선택 가능 |
| 음식 추천 엔진 | ✅ 완료 | 기분×카테고리 조합으로 랜덤 음식 추천 |
| 추천 결과 화면 | ✅ 완료 | 음식 사진, 설명, 효과, 희귀도 표시 |
| 재추천 기능 | ✅ 완료 | 같은 조건으로 다른 음식 재추천 |

### 2.2 회원 시스템
| 기능 | 상태 | 설명 |

| 로그인 | ✅ 완료 | `/login` 페이지, Spring Security 인증 |
| 로그아웃 | ✅ 완료 | 세션 종료 |

### 2.3 마이페이지 (감정 일기)

|------|------|------|
| 카드 자동 저장 | ✅ 완료 | 추천 결과가 자동으로 마이페이지에 카드로 저장 |
