## 3. 화면 상세 정의 / 画面詳細定義

### 3.1 SCR-001: 톱 (トップ)

#### 3.1.1 기본 정보 / 基本情報
| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-001 |
| **화면 이름** | 톱 / トップ |
| **URL** | `/` |
| **접근 권한** | 누구나 / 誰でも |

#### 3.1.2 화면 목적 / 画面目的
> 사용자의 현재 기분을 6가지 감정 중에서 선택하는 초기 화면

```

│                                         │
│                                         │
│   ┌─────────┐  ┌─────────┐  ┌─────────┐│

#### 3.1.4 화면 구성 요소 / 画面構成要素

| 구성 요소 | 유형 | 내용 | 동작 |
|----------|------|------|------|
| 로고 | 텍스트 | きぶんめし | 클릭 시 페이지 새로고침 |
| 메인 타이틀 | 텍스트 | 오늘의 기분은? / 今日の気分は？ | - |
| 감정 버튼 1 | 버튼 | 😊 기쁨 / うれしい | 클릭 → `/category?emotion=1` |
| 감정 버튼 2 | 버튼 | 😢 슬픔 / かなしい | 클릭 → `/category?emotion=2` |
| 감정 버튼 3 | 버튼 | 😠 화남 / おこ | 클릭 → `/category?emotion=3` |
| 감정 버튼 4 | 버튼 | 😴 피곤 / つかれた | 클릭 → `/category?emotion=4` |
| 감정 버튼 5 | 버튼 | 🤩 신남 / わくわく | 클릭 → `/category?emotion=5` |
| 감정 버튼 6 | 버튼 | 😌 평온 / おだやか | 클릭 → `/category?emotion=6` |
| 히스토리 링크 | 링크 | 히스토리 보기 → / 履歴を見る → | 클릭 → `/history` (옵션) |

| 이벤트 | 조건 | 전환 화면 |
|--------|------|----------|
| 감정 버튼 클릭 | 6개 버튼 중任意 클릭 | SCR-002 카테고리 선택 |
| 로고 클릭 | 로고 영역 클릭 | 현재 페이지 새로고침 |
| 히스토리 링크 클릭 | 히스토리 링크 클릭 | SCR-004 히스토리 (옵션) |

### 3.2 SCR-002: 카테고리 선택 / カテゴリ選択

#### 3.2.1 기본 정보 / 基本情報

#### 3.2.2 화면 목적 / 画面目的
> 선택한 감정을 바탕으로, 어떤 종류의 음식을 먹고 싶은지 카테고리를 선택하는 화면

```

│                                         │

│                                         │

│    / [← 気分を選び直す]                  │
│                                         │
└─────────────────────────────────────────┘

#### 3.2.4 화면 구성 요소 / 画面構成要素

| 구성 요소 | 유형 | 내용 | 동작 |
|----------|------|------|------|
| 로고 | 텍스트 | きぶんめし | 클릭 → `/` (톱) |
| 선택된 감정 표시 | 배너 | 【기쁨】기분에는... / 【うれしい】気分には... | 조회용 (감정 색상 배경) |
| 카테고리 버튼 1 | 버튼 | 🥘 한식 / 韓国料理 | 클릭 → `POST /result` (emotionId, categoryId=1) |
| 카테고리 버튼 2 | 버튼 | 🍔 양식 / 洋食 | 클릭 → `POST /result` (emotionId, categoryId=2) |
| 카테고리 버튼 3 | 버튼 | 🥟 중식 / 中華 | 클릭 → `POST /result` (emotionId, categoryId=3) |
| 카테고리 버튼 4 | 버튼 | 🍣 일식 / 和食 | 클릭 → `POST /result` (emotionId, categoryId=4) |
| 카테고리 버튼 5 | 버튼 | 🍕 기타 / その他 | 클릭 → `POST /result` (emotionId, categoryId=5) |
| 뒤로 가기 버튼 | 링크 | ← 감정 다시 선택하기 / ← 気分を選び直す | 클릭 → `/` (톱) |

#### 3.2.5 화면 전환 / 画面遷移

| 이벤트 | 조건 | 전환 화면 |

### 5.4 모바일 퍼스트 설계 / モバイルファースト設計
> 모든 컴포넌트는 모바일 레이아웃을 기본으로 설계하고, `min-width` 미디어 쿼리로 태블릿/데스크탑 스타일을 확장합니다.

```css
/* 모바일 기본 스타일 */
.emotion-btn {
  width: 60px;
  height: 60px;
}

/* 태블릿 */
@media (min-width: 768px) {
  .emotion-btn {
    width: 70px;
    height: 70px;
  }
}

/* 데스크탑 */
@media (min-width: 1024px) {
  .emotion-btn {
    width: 80px;
    height: 80px;
  }
}
```
