## 2. JDK 17 설치

### Step 1: JDK 다운로드
1. [Adoptium Temurin 17](https://adoptium.net/temurin/releases/?version=17) 접속
2. **Operating System**: `Windows`
3. **Architecture**: `x64`
4. **Package Type**: `MSI Installer`
5. 최신 버전 다운로드 (예: `jdk-17.0.12+7.msi`)

### Step 2: JDK 설치
1. 다운로드한 MSI 파일 실행
2. **Next** → **Next** → **Install** → **Finish**
3. 기본 설치 경로: `C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot\`

### Step 3: 환경 변수 설정 (JAVA_HOME)
1. **Windows 키 + R** → `sysdm.cpl` 입력 → Enter
2. **고급** 탭 → **환경 변수** 클릭
3. **시스템 변수** → **새로 만들기**
   - 변수 이름: `JAVA_HOME`
   - 변수 값: JDK 설치 경로 (예: `C:\Program Files\Eclipse Adoptium\jdk-17.0.12-hotspot`)
4. **시스템 변수** → `Path` 찾아서 **편집**
   - **새로 만들기** → `%JAVA_HOME%\bin` 추가
   - 맨 위로 이동 (선택 사항이지만 권장)
5. **확인** → **확인** → **확인**으로 모두 닫기

### Step 4: 설치 확인
1. **명령 프롬프트(CMD)** 열기
2. 다음 명령 실행:
   ```cmd
   java -version
   javac -version
   ```
3. 버전이 17.x로 표시되면 성공!

## 3. Eclipse IDE 설치

### Step 1: Eclipse 다운로드
1. [Eclipse Downloads](https://www.eclipse.org/downloads/) 접속
2. **Download x86_64** 클릭 → **Download** 클릭
3. `eclipse-inst-jre-win64.exe` 다운로드

### Step 2: Eclipse 설치
1. Installer 실행
2. **Eclipse IDE for Enterprise Java and Web Developers** 선택
3. **Installation Folder** 원하는 경로로 설정 (예: `C:\eclipse`)
4. **Install** 클릭 → **Accept Now** → **Trust All**
5. 설치 완료 후 **Launch** 클릭

### Step 3: Workspace 설정
1. Workspace 경로 지정 (예: `C:\Users\[사용자명]\workspace`)
2. **Launch** 클릭

## 4. MySQL 8.0 설치

### Step 1: MySQL Installer 다운로드
1. [MySQL Community Server 다운로드](https://dev.mysql.com/downloads/mysql/)
2. **MySQL Installer for Windows** 클릭 (권장)
3. **Download** 클릭 → **No thanks, just start my download.** 클릭
4. `mysql-installer-community-8.0.x.x.msi` 다운로드

### Step 2: MySQL 설치 (Developer Default)
1. Installer 실행
2. **Choosing a Setup Type**: `Developer Default` 선택 → **Next**
3. **Check Requirements**: **Next** → **Execute** (필요한 소프트웨어 자동 설치)
4. **Installation**: **Execute** → **Next**
5. **Product Configuration**: **Next**
6. **Type and Networking**: 기본값 그대로 → **Next**
7. **Authentication Method**: `Use Strong Password Encryption` 선택 → **Next**
8. **Accounts and Roles**:
   - **Root Password**: `root1234` (간단한 비밀번호로 설정, 나중에 변경 가능)
   - **Add User** (선택): 나중에 해도 됨 → **Next**
9. **Windows Service**: 기본값 그대로 → **Next**
10. **Apply Configuration**: **Execute** → **Finish**
11. **Product Configuration**: **Next** → **Finish**

### Step 3: MySQL Workbench로 접속 확인 (선택)
1. **MySQL Workbench** 실행
2. **Local instance MySQL80** 클릭
3. 비밀번호 입력 → **OK**
4. 접속되면 성공!

## 5. 프로젝트 Import & 설정

### Step 1: 프로젝트 폴더 복사
- 기존 PC의 `kibunmeshi` 폴더를 USB나 클라우드로 새 PC로 복사
- 새 PC의 적절한 위치에 저장 (예: `C:\portfolio\kibunmeshi`)

### Step 2: Eclipse에 Gradle 프로젝트로 Import
1. Eclipse 실행
2. **File** → **Import**
3. **Gradle** → **Existing Gradle Project** → **Next**
4. **Project root directory**: 복사한 `kibunmeshi` 폴더 선택 → **Next**
5. **Gradle Wrapper** 선택 → **Next** → **Finish**
6. Gradle이 의존성을 다운로드할 때까지 잠시 기다리기 (오른쪽 하단 Progress 확인)

### Step 3: 프로젝트 빌드
1. **Package Explorer**에서 `kibunmeshi` 프로젝트 우클릭
2. **Gradle** → **Refresh Gradle Project**
3. 빌드가 완료될 때까지 기다리기

## 6. 데이터베이스 설정

### Step 1: MySQL에 데이터베이스와 사용자 생성
1. **MySQL Workbench** 열고 **Local instance MySQL80** 접속
2. 다음 SQL 쿼리 실행:

```sql
-- 1. 데이터베이스 생성
CREATE DATABASE IF NOT EXISTS kibunmeshi
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

-- 2. 사용자 생성 (application.yml과 일치시킴)
CREATE USER IF NOT EXISTS 'kibunmeshi_user'@'localhost' IDENTIFIED BY 'kibunmeshi_pass';

-- 3. 권한 부여
GRANT ALL PRIVILEGES ON kibunmeshi.* TO 'kibunmeshi_user'@'localhost';
FLUSH PRIVILEGES;

-- 4. 확인
SHOW DATABASES;
SELECT user, host FROM mysql.user;
```

### Step 2: application.yml 확인 (필요시 수정)
프로젝트 내 `src/main/resources/application.yml` 파일 열어서 다음 내용 확인:

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/kibunmeshi?useSSL=false&serverTimezone=Asia/Tokyo&characterEncoding=UTF-8&allowPublicKeyRetrieval=true
    username: kibunmeshi_user    # 위에서 생성한 사용자명
    password: kibunmeshi_pass    # 위에서 설정한 비밀번호
    driver-class-name: com.mysql.cj.jdbc.Driver
  server:
    port: 8081  # 포트가 8081로 설정되어 있는지 확인
```

**주의**: 비밀번호를 다르게 설정했다면 여기도 변경해야 함!

## 7. 애플리케이션 실행

### Step 1: Eclipse에서 실행
1. **Package Explorer**에서 `src/main/java/com/kibunmeshi/KibunmeshiApplication.java` 찾기
2. 파일 우클릭 → **Run As** → **Java Application**
3. 콘솔 로그 확인: `Started KibunmeshiApplication in x.xxx seconds`가 보이면 성공!

### Step 2: 브라우저로 접속
1. 브라우저 열기
2. 주소창에 `http://localhost:8081` 입력
3. 기분 선택 화면이 보이면 완료! 🎉

### Step 3: 테스트
1. 기분 선택 → 카테고리 선택 → 추천 결과 확인
2. **회원가입** → **로그인** → 다시 추천 → 마이페이지에 카드가 저장되는지 확인

## 트러블슈팅

### 문제 1: Gradle Import 오류
- **증상**: 프로젝트 Import시 빨간 줄이 많이 생김
- **해결**:
  1. **Window** → **Preferences** → **Gradle**
  2. **Gradle User Home** 확인 (보통 `C:\Users\[사용자명]\.gradle`)
  3. 프로젝트 우클릭 → **Gradle** → **Refresh Gradle Project**

### 문제 2: MySQL 연결 오류
- **증상**: `Communications link failure`
- **해결**:
  1. MySQL 서비스가 실행 중인지 확인:
     - **Windows 서비스** → `MySQL80` → 상태가 **실행 중**인지
  2. 포트 3306이 사용 중인지 확인
  3. `application.yml`의 username/password가 정확한지

### 문제 3: 포트 8081이 이미 사용 중
- **증상**: `Port 8081 was already in use`
- **해결**:
  1. `application.yml`에서 `server.port`를 다른 값으로 변경 (예: 8082)
  2. 또는 사용 중인 프로세스 종료:
     ```cmd
     netstat -ano | findstr :8081
     taskkill /PID [PID번호] /F
     ```

### 문제 4: JDK 버전 문제
- **증상**: `Unsupported class file major version`
- **해결**:
  1. **Window** → **Preferences** → **Java** → **Installed JREs**
  2. **Add** → **Standard VM** → **Directory** → JDK 17 경로 선택
  3. 프로젝트 우클릭 → **Properties** → **Java Build Path** → **Libraries**
  4. **Modulepath**에 JDK 17이 있는지 확인
  5. **Java Compiler** → **Compiler compliance level** → 17로 설정

## 부록: 명령줄로 실행하는 방법 (Eclipse 없이)

Eclipse를 사용하지 않고 직접 실행하려면:

1. **CMD**에서 `kibunmeshi` 폴더로 이동
2. 다음 명령 실행:
   ```cmd
   gradlew.bat bootRun
   ```
3. 빌드가 완료되면 `http://localhost:8081` 접속
