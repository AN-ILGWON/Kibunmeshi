## 1. 프로젝트 개요 / プロジェクト概要

### 1.1 서비스 개념 / サービスコンセプ트
> **한국어**: 오늘 기분만 선택하면 딱 맞는 음식과 마음에 위로가 되는 한 마디를 전달하는 웹 서비스  
> **日本語**: 今日の気分を選ぶだけで、ぴったりのごはんと心に寄り添う一言をお届けするWebサービス

### 1.2 프로젝트 정보 / プロジェクト情報
| 항목 / 項目 | 내용 / 内容 |
|------------|------------|
| **서비스명 / サービス名** | 키분메시 (きぶんめし / Kibunmeshi) |
| **제작 기간 / 制作期間** | 2주일 (14일간) / 2週間（14日間） |
| **타겟 사용자 / ターゲットユーザー** | 일본에 거주하는 20~30대 / 日本在住の20~30代 |
| **운영 환경 / 運用環境** | 웹 브라우저 (PC/스마트폰) / Webブラウザ（PC/スマートフォン） |

### 1.3 핵심 가치 / コアバリュー
| # | 가치 / 価値 | 설명 / 説明 |
|---|-----------|------------|
| 1 | **간단함 / シンプル** | 2클릭으로 결과 확인 / 2クリックで結果確認 |
| 2 | **공감 / 共感** | 기분에 맞는 조언 제공 / 気分に合ったアドバイス提供 |
| 3 | **시각적 즐거움 / ビジュアルな楽しさ** | 예쁜 음식 사진 / 美しい料理写真 |

### 2.2 기능 상세 / 機能詳細

#### FR-001: 감정 선택 / 気分選択
| 항목 | 내용 |
|------|------|
| **설명** | 사용자가 현재 기분을 6가지 중 선택 |
| **입력** | 없음 (초기 화면) |
| **출력** | 선택된 감정 ID |
| **화면 이동** | `/category?emotion={id}` |
| **제약사항** | 필수 선택, 중복 선택 불가 |

**감정 목록 / 感情リスト:**
| ID | 한국어 | 일본어 | 이모지 | 색상 |

| 2 | 슬픔 | かなしい | 😢 | #6495ED |
| 3 | 화남 | おこ | 😠 | #DC143C |
| 4 | 피곤 | つかれた | 😴 | #708090 |
| 5 | 신남 | わくわく | 🤩 | #FF6347 |
| 6 | 평온 | おだやか | 😌 | #90EE90 |

#### FR-002: 음식 카테고리 선택 / 料理カテゴリ選択
| 항목 | 내용 |
|------|------|
| **설명** | 사용자가 원하는 음식 카테고리 선택 |
| **입력** | 감정 ID (URL 파라미터) |
| **출력** | 선택된 카테고리 ID |
| **화면 이동** | `/result` (POST) |
| **제약사항** | 필수 선택, 중복 선택 불가 |

**카테고리 목록 / カテゴリリスト:**
| ID | 한국어 | 일본어 | 아이콘 |
|----|-------|--------|--------|
| 1 | 한식 | 韓国料理 | 🥘 |
| 2 | 양식 | 洋食 | 🍔 |
| 3 | 중식 | 中華 | 🥟 |
| 4 | 일식 | 和食 | 🍣 |
| 5 | 기타 | その他 | 🍕 |

#### FR-003: 음식 추천 / 料理推薦
| 항목 | 내용 |
|------|------|
| **설명** | 선택된 감정과 카테고리에 맞는 음식을 DB에서 랜덤 선택 |
| **입력** | emotionId, categoryId |
| **출력** | Food 객체 (음식 정보 전체) |
| **처리 로직** | 1. DB에서 조건에 맞는 foods 조회 → 2. 랜덤으로 1개 선택 → 3. 결과 반환 |
| **에러 처리** | 데이터 없을 경우: 기본 음식 반환 또는 에러 메시지 |

#### FR-004: 조언 표시 / アドバイス表示
| 항목 | 내용 |
|------|------|
| **설명** | 추천된 음식에 어울리는 한 마디 조언 표시 |
| **입력** | Food.adviceTemplate |
| **출력** | 완성된 조언 문장 |
| **처리 로직** | 템플릿 내 【음식명】 등의 플레이스홀더를 실제 값으로 치환 |

**조언 템플릿 예시 / アドバイステンプレート例:**
| 상황 / 状況 | 템플릿 / テンプレート |
|------------|---------------------|
| 기쁨 + 어떤 음식 | "오늘의 기쁨을 【음식명】(와)과 함께 만끽하세요" |
| 슬픔 + 따뜻한 음식 | "【음식명】의 따뜻함으로 마음을 위로받으세요" |
| 피곤 + 보양식 | "【음식명】으로 지친 몸에 활력을 채우세요" |

#### FR-005: 음식 이미지 표시 / 料理画像表示
| 항목 | 내용 |
|------|------|
| **설명** | Unsplash API를 사용하여 음식 관련 이미지 검색 및 표시 |
| **입력** | Food.imageKeyword (검색용 키워드) |
| **출력** | 이미지 URL |
| **처리 로직** | 1. 키워드로 Unsplash API 검색 → 2. 결과 중 1개 선택 → 3. URL 반환 |
| **대체 방안** | API 실패 시: 기본 이미지 URL 사용 |

#### FR-006: 재추천 기능 / 再推薦機能
| 항목 | 내용 |
|------|------|
| **설명** | 동일 조건(감정+카테고리)으로 다른 음식 재추천 |
| **입력** | 현재 선택된 emotionId, categoryId |
| **출력** | 새로운 Food 객체 |
| **처리 로직** | 이전 추천 제외 또는 전체 중 재랜덤 선택 |
| **화면 동작** | 결과 페이지 내에서 새로고침 없이 내용 갱신 |

## 5. 용어 정의 / 用語定義

| 한국어 | 일본어 | 영어 | 정의 / 定義 |
|-------|--------|------|-----------|
| 감정 | 気分 | Emotion | 사용자의 현재 기분 상태 / ユーザーの現在の気分状態 |
| 음식 카테고리 | 料理カテゴリ | Food Category | 음식의 국가/종류 분류 / 料理の国/種類分類 |
| 음식 | 料理 | Food | 추천 대상이 되는 구체적인 음식 / 推薦対象となる具体的な料理 |
| 조언 | アドバイス | Advice | 음식과 함께 제공되는 위로의 한 마디 / 料理と共に提供される慰めの一言 |
| 재추천 | 再推薦 | Re-recommend | 동일 조건으로 다른 음식을 다시 추천 / 同条件で別料理を再度推薦 |
