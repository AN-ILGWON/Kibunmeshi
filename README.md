# きぶんめし (Kibunmeshi)

> 기분에 따라 음식을 추천해주는 웹 서비스

## 프로젝트 개요
- **제작 기간**: 2주
- **타겟**: 일본 사용자
- **핵심 기능**: 감정 선택 + 음식 종류 선택 → 음식 추천 + 조언 제공

## 기술 스택
- Backend: Spring Boot 3.x, Spring Security, MyBatis
- Frontend: Thymeleaf
- Database: MySQL
- External API: Unsplash (음식 이미지)
